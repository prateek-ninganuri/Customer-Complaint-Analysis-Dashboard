## 📌 Project Overview

This Tableau dashboard enables users to explore customer complaints using interactive filters and visualizations. It provides a comprehensive view of complaint trends across financial products, geographic regions, and submission channels to support data-driven decision-making.

---

## 🎯 Objectives

- Analyze complaint trends over time.
- Compare complaints across financial products.
- Identify state-wise complaint distribution.
- Understand customer complaint submission channels.
- Build an interactive dashboard for business insights.

---

## 📊 Dashboard Features

- KPI cards for total and product-wise complaints
- Product and map selection filters
- Year-wise complaint analysis
- State-wise complaint distribution (Map/Tile Chart)
- Complaint breakdown by submission channel
- Interactive yearly trend analysis

---

---

## 📈 Key Insights

- Analyzed over **72,000 customer complaints**.
- Credit Card and Other Financial Services recorded the highest complaint volumes.
- Web was the most commonly used complaint submission channel.
- Complaint trends remained relatively consistent across the years.
- State-wise analysis identified regions with higher complaint volumes.
